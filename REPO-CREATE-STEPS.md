# ONE-TIME REPOSITORY CREATION

The current GitHub connector can edit existing repositories but cannot create a brand-new repository.

Create one empty repository in GitHub:

- Suggested temporary name: `project-guildfall`
- Visibility: your preference; private is sensible while the concept is forming
- Do **not** auto-add README / .gitignore / license, because this starter already contains them

Then, in the next session, send only the repository URL and paste `NEW-SESSION-PROMPT.md`.
The assistant can then push these starter files into the empty repository and begin D001.
