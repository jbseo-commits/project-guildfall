# VERTICAL SLICE V3 — AUTOBATTLER TUTORIAL CHAPTER

## Why V3 exists

V2 improved narrative attachment, but the strategic interaction was still too shallow to teach the game as an autobattler.

V3 turns the prototype into a four-lesson tutorial chapter that teaches the actual strategic grammar:

**READ → BUILD → COMMIT → WATCH → UNDERSTAND**

## Tutorial structure

### Lesson I — Formation
The player reads a visible enemy intent and decides who occupies:
- FRONT / 외피
- CORE / 심장
- VEIL / 장막

Position changes both risk and behavior.

### Lesson II — Resonance
The player links two inhabitants to create a visible automatic reaction chain:

**TRIGGER → REACTION → PAYOFF**

Examples:
- Seris takes heavy damage → Vael intercepts → ritual survives.
- Mirel heals → Vael guards harder → frontline survives.
- Seris is healed → ritual accelerates → faster burst.

### Lesson III — Edict
The player chooses one battle-wide tactical principle:
- DEFEND / 껍질을 닫아
- RITUAL / 달을 끝까지 띄워
- SUSTAIN / 뿌리를 깊게

Each has an explicit strength and trade-off.

### Final — Independent Exam
No recommended answer is shown.

The player reads enemy intents and combines:
- formation;
- resonance;
- edict;

then commits and watches the ecosystem resolve combat automatically.

## Tutorial UX rules

- Only one new system is introduced per lesson.
- A guided overlay highlights one UI region at a time.
- Enemy intents are visible before combat.
- There is a hard COMMIT boundary.
- No micro-control after COMMIT.
- Every battle ends with a cause-chain debrief explaining:
  **player choice → automatic trigger → visible consequence**.
- The final exam removes tutorial recommendations.

## What V3 is testing

1. Does this now read as an autobattler rather than a scripted combat scene?
2. Can the player explain the game loop after four encounters?
3. Do formation, resonance, and edict produce visibly different battle behavior?
4. Does the cause-chain debrief make automatic combat legible?
5. Does the player want to replay the final exam with a different build?

## Still prototype assumptions

None of the following are yet locked as D002/D003 final design:
- three fixed formation slots;
- one resonance link;
- one battle edict;
- exact numeric bonuses;
- exact enemy intent language.

These are tutorial hypotheses used to test the strategic grammar.

## Long-term mastery direction

The tutorial intentionally starts simple, but the mastery ceiling may later include:
- dual resonance;
- conditional instinct priorities;
- thresholds such as HP < 40%;
- caravan-organ interactions;
- more detailed behavior scripting.

These are direction previews, not locked systems.
